## FAQ

### What is XCutors?

XCutors is a collection of popular Roblox script executor tools bundled together with a universal loader, making it easy to manage and switch between multiple executors on Windows.

### Which executors are included in the pack?

The bundle includes Volt, Synapse Z, Potassium, Wave, and the xCutorsLoader universal loader that ties them all together.

### Is XCutors free to use?

Yes, XCutors and its loader are free. However, some individual executors included in the bundle may have their own separate licensing or subscription requirements.

### What operating systems are supported?

XCutors currently supports Windows 10 and Windows 11 (64-bit). macOS and Linux are not supported at this time.

### Do I need to disable my anticomponent software?

Some anticomponent programs may flag executor files as potentially unwanted programs (PUPs). You may need to add an exception for the XCutors installation folder. Always download only from the official GitHub repository to ensure file integrity.

### How do I update the executors?

Open xCutorsLoader and click 'Check for Updates'. The built-in updater will automatically download and apply the latest versions of all included executors.

### Where can I find scripts to use?

XCutors includes a built-in script hub with community-contributed scripts organized by category. You can also paste your own custom Lua scripts directly into the integrated editor.

### The executor is not attaching to Roblox. What should I do?

Ensure Roblox is fully running and you are in an active game session. Right-click the executor and run it as Administrator. If the problem persists, verify that your anticomponent is not blocking the process and that you are on the latest executor version.

### Can I use multiple executors at the same time?

It is strongly recommended to use only one executor at a time to avoid runtime conflicts. The universal loader makes it simple to switch between them as needed.

### How do I report a bug or request a new feature?

Navigate to the Issues tab on the GitHub repository and open a new issue. Provide a detailed description, steps to reproduce (for bugs), and your system information for the fastest response.
